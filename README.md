# Nacreline Fog Harp Mk3 — Design Package

Design package for the **Nacreline Fog Harp Mk3**, the successor revision after Rev 2.
This repository implements design ID `NFH-3`; the mesh geometry, tensioner clips and
controller board are **not** compatible with the earlier NFH-2 package. For Rev 2 builds
use the NFH-2 repository instead.

## Status
Released after the 2026 autumn pilot. All Mk3 fabrication files are final.
